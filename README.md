# 🚗 RIDEMATE

A modern Ride Sharing Platform built using **HTML, CSS, JavaScript, Node.js, and Express.js**. RIDEMATE allows users to create rides, browse available rides, search routes, book rides, and manage ride listings through a clean and responsive interface.

---

## 📌 Features

* ✅ Create new ride listings
* ✅ View all available rides
* ✅ Search rides by source or destination
* ✅ Book a ride
* ✅ Delete ride listings
* ✅ Driver information display
* ✅ Ride pricing information
* ✅ Responsive and modern UI
* ✅ Local storage support
* ✅ Node.js + Express backend

## 🚀 How to Run

### 1. Clone Repository

```bash
git clone https://github.com/hiteshmaddi/RIDEMATE.git
```

### 2. Open Project

```bash
cd RIDEMATE
```

### 3. Install Backend Dependencies

```bash
cd backend
npm install
```

### 4. Start Backend Server

```bash
npm start
```

Server runs at:

```text
http://localhost:3000
```

### 5. Open Frontend

Open:

```text
frontend/index.html
```

Or use VS Code Live Server.
